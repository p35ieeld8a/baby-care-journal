# 接种完乙肝疫苗，宝宝还要做抗体检测吗？

> 更新时间：2026-09-17 (UTC+8)

**官方微信平台，点击上方欢迎订阅**

**接种乙肝疫苗是预防乙肝病毒感染最有效的措施，**新生儿出生后，如果没有特殊情况，一般会在0-1-6月接种3针的乙肝疫苗。

那么，接种乙肝疫苗之后就万事大吉了吗？

当然不是。有研究表明，我国儿童出生后，即使完成了3针全程乙肝疫苗接种，还是有部分孩子出现无应答或低应答现象。

乙肝妈妈所生的孩子，即使出生后接种了乙肝疫苗，并注射了乙肝免疫球蛋白，也还是有大约5%的新生儿发生了乙肝病毒感染。**儿童感染乙肝病毒后，往往没有明显的临床表现，但慢性化的风险却远远高于成人，**因此为降低乙肝病毒感染的风险，或对已经感染了乙肝病毒的儿童，尽可能做到早发现、早治疗。

我国最新的《儿童慢性乙肝防治专家共识》建议，我们应该加强儿童乙肝病毒的筛查。

**那么，具体应该怎么做呢？**

首先对于乙肝妈妈分娩的婴儿，或可能密切接触到乙肝患者的婴儿，为了更早地明确是否感染了乙肝，以及感染状态，可在接种第2剂疫苗1-2个月后（正常就是3月龄左右），进行乙肝检测。

就算没有上述危险因素，**婴儿在完成全程疫苗接种后1-2个月，或免疫接种无应答的儿童补种后1-2个月，也可以进行乙肝的检测，**还有部分儿童完成了乙肝疫苗的接种，在他小的时候乙肝抗体水平是比较高的，但是随着年龄的增长，保护性的抗体会逐渐减少，这时乙肝脱发性感染的风险也会显著增加。

因此，对于高危人群或免疫功能低下的儿童，特别是平时可能密切接触到乙肝携带者的儿童，应该加强乙肝抗体的检测，必要时可进行乙肝疫苗的加强接种。
