# 北京生物新冠疫苗一共打两针还是三针？

> 更新时间：2026-09-16 (UTC+8)

我们公司主要做的是服务业，公司专门给我们安排的三针新冠疫苗接种，在公司附近的两个接种点去接种就可以了。昨天我跑去了，但是直接给刷的身份证，没有拿公司的预约单子，我看我接种的是北京生物新冠疫苗，回公司后大家都说自己接种的是安徽智飞，难道我打成两针的了？北京生物新冠疫苗一共打两针还是三针？ 
查看全部内容

北京生物新冠疫苗属于新冠灭活疫苗一共只打两针，打三针的是安徽智飞的重组蛋白新冠疫苗。两者并不属于同一种类新冠疫苗，作用方式是不一样的，如果打错了疫苗了也没关系，两针的北京生物新冠灭活疫苗防护效果跟三针是差不多的。但需注意同类型新冠疫苗两针混打是可以的，但不同类型的就不可以，打了北京生物的第一针疫苗后是不可以打安徽智飞的新冠疫苗的。

北京生物疫苗是首家获批的国产新冠病毒灭活疫苗，该疫苗第一针接种10天后可以产生抗体，接种两到四周后接种第二针，两针注射后，再过14天，可产生高滴度抗体，形成有效保护。目前该疫苗接种后中和抗体阳转率为99.52%，保护效力为79.34%，并且安全性非常高，只有少部分人群出现了中轻度不良反应。以下是接种北京生物疫苗小建议：

- 1. 接种前，应提前了解新冠疾病、新冠疫苗相关知识及接种流程；
- 2. 如果接种部位有伤口，尽量避开伤口选择另一侧接种；
- 3. 向医生主动提供自己健康状况，近期服用的药物信息，并如实填写知情同意书；
- 4. 接种完毕，需在接种点留观30分钟；
- 5. 接种两针新冠疫苗间隔时间最好在三周和四周，免疫的持久性、抗体阳转的水平、抗体平均值等各项指标均好于间隔一周和两周。
据国药集团介绍目前中国生物新冠灭活疫苗分别在阿联酋、巴林、玻利维亚、塞舌尔获批正式注册上市。在印度尼西亚、土耳其、巴西、智利、哥伦比亚、乌拉圭、老挝、墨西哥、泰国、马来西亚等多个国家已获批科兴疫苗紧急使用。截至目前，国内外已接种4400多万剂次。
